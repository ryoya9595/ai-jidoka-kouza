RISE AI自動化講座

配布物は、
URLを貼るだけ。

各回で使う手順書やスキルを、ここにまとめています。使いたい回の「コピー」を押して、作業フォルダを開いた Claude Code に貼り付けて送信するだけ。あとは Claude Code が順番に案内してくれます。

00

使い方 — 3ステップ

  1. Claude Code（デスクトップアプリの「Code」）で、自分の作業フォルダを開く（第3回で作ったフォルダ）
  2. 下の一覧から、今見ている回の「コピー」を押す
  3. Claude Code の入力欄に貼り付けて送信。質問されたら答える。「許可しますか？」が出たら許可する
✅手順書はただの文章です。Claude Code が読んで、あなたと会話しながら進めます。パスワードの入力やアカウント作成は、必ず自分でブラウザからやってください（Claude Code に代わりにやらせない）。

💳 Claude Code を使うのに必要なプラン（最新）

Claude Code は 無料プランでは使えません。Pro 以上の有料プランが必要です（この講座は Pro で進められます）。料金は変わることがあるので、動画では言っていません。ここが最新の情報です。

  • Pro：月20ドル（年払いだと月17ドル相当）。基本これでOK
  • Max：月100ドル〜。たくさん使って上限にすぐ届く人向け
  • クラウドの自動実行（第12回）やスマホのクラウド版（第13回）も、有料プランで使えます

最新の料金は公式ページで確認 → claude.com/pricing（最終確認：2026-10-05）

📣主流のAIエージェントは時期によって変わります。大きな変化があれば、このページでお知らせします。この講座は Claude Code を例に解説していますが、Codex など他のAIエージェントでも考え方は同じです。
🤖 Claude Code へ：このページのURLだけを渡されたら、「AI自動化講座の何回目の配布物を使いたいか」を1問だけ聞いて、該当する手順書のURL（下の一覧の files/…）を curl（Windows は curl.exe）で取得して全文を読み、作業フォルダには保存せず、その手順どおりに、いま開いている作業フォルダで進めてください。何かを作る前には、手順書のとおりユーザーの了承を取ってください。

Claude Code のダウンロードと初期設定 読む手順書

Claudeアカウント・有料プラン・アプリのダウンロード・GitHubアカウント作成・Chrome拡張。自分で読んで進める手順書です。つまずいたら、下のメッセージを Claude Code に貼ると案内してくれます。

「ローカルセッションにはGitが必要です」と出た方：Windows は警告の下の「Git for Windows をダウンロード」→全部そのまま「Next」→Claude を完全終了して開き直す。Mac はポップアップの「インストール」を押す。くわしくは手順書の「4」。

作業フォルダを GitHub につなごう Claude Code に読ませる

      
作業フォルダの中身を作って、GitHub の非公開リポジトリに保管し、スマホ・自動実行から使えるようにする。先に空のフォルダを1つ作って、Claude Code で開いてから貼ってください。

      
Windowsの方：フォルダを選ぶ画面の上の「場所」の欄をクリックして %USERPROFILE% と入力→Enter で「自分の名前のフォルダ」が開きます（「ホーム」ではありません）。そこに「新しいフォルダー」で作ってください。デスクトップ／ドキュメントは OneDrive が同期しているので避けます。

困ったとき

  

    
    
      
  • エラーが出た → エラーの文章をそのまま Claude Code に貼って「どういう意味？」と聞く
    • 
      
  • Claude Code が手順書を読めない → 「📄 中身」のリンクを開いて、全文をコピーして Claude Code に貼る（ファイルをダウンロードして作業フォルダに入れてもOK）
    • 
      
  • 画面の名前が動画と違う → アップデートで変わることがあります。似た名前のものを探すか、Claude Code に「今の画面で〇〇はどこ？」と聞く
    • 
      
  • それでも解決しない → 質問部屋へ。やったこと・出たエラー・スクショを添えてください

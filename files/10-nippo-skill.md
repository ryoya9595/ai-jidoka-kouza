# Claude Code 向け：「日報スキル」のインストール手順

> RISE「AI自動化講座」10回目の配布物。受講生は、作業フォルダにこのファイルを入れて「このファイルをスキルとして入れて」と送るだけ。
> Claude Code は次の2つを行う：
> 1. 下の「インストールするスキル」を、作業フォルダの `.claude/skills/my-nippo/SKILL.md` として保存する
> 2. 作業フォルダの `CLAUDE.md` の末尾に、下の「CLAUDE.md に足すルール」を追記する（既存の内容は消さない）
> 終わったら「/my-nippo で今日の日報が作れます。今日から、大事なことを決めたら daily に短くメモしていきますね」と伝え、このファイル（日報スキル.md）は消してよいか聞く。
> 配布URL：https://ryoya9595.github.io/ai-jidoka-kouza/files/10-nippo-skill.md 。受講生がこのURLを貼って「読んで進めて」と送った場合は、curl（Windows は curl.exe）で全文を取得して読み、手順書そのものは作業フォルダに保存しない（ファイルを入れて「日報スキル.md を読んで」と言われた場合と同じ手順で進める）。

---

## CLAUDE.md に足すルール

（下の ```markdown の囲みの「中身だけ」を追記する。囲みの行 ``` は含めない。**すでに CLAUDE.md に「作業の始まりと記録」の章（AI秘書セットアップで入る、daily にメモするルール）がある場合は、この章は足さず、そのままでよい**。無い場合だけ足す）

```markdown
## 日報のためのメモ
- 何かを決めたとき・作業が一区切りしたとき・新しいものを作ったときは、`daily/YYYY-MM-DD.md`（今日の日付・日本時間。`TZ=JST-9 date +%F` で出す）の「## メモ」の末尾（「## 日報」より上）に1〜3行で追記する。ファイルが無ければ `# YYYY-MM-DD` と `## メモ` の見出しを作ってから書く
- 書き方：`- HH:MM やったこと／決めたこと（関係するファイル）`（時刻は `TZ=JST-9 date +%H:%M`）
- 許可は取らずに書いてよい。書いたら返事の最後に「（📝 メモしました）」と小さく添える
- 秘密の情報・個人情報はメモに書かない
```

---

## インストールするスキル（下の ```markdown の囲みの「中身だけ」を SKILL.md として保存する。囲みの行 ``` は含めない）

```markdown
---
name: my-nippo
description: その日の作業をまとめて日報を作る。daily のメモと、その日に作ったり変えたりしたファイルをもとに「やったこと／決めたこと／明日やること」にまとめる。「日報」「日報作って」「今日のまとめ」「/my-nippo」で使う。決まった時間の自動実行（ルーティン）からも使う。
---

# my-nippo — 日報をつくる

## 使う材料
1. 今日の日付（日本時間）：`TZ=JST-9 date +%F`（どの環境でも動く書き方。PowerShell なら `Get-Date -Format yyyy-MM-dd`）
2. `daily/今日の日付.md` の「## メモ」
3. 今日の変更の記録（日本時間の0時から）：
   `D=$(TZ=JST-9 date +%F); TZ=JST-9 git log --since="$D 00:00:00 +0900" --name-only --pretty=format:"%h %cd %s" --date=format-local:%H:%M`
   - クラウドで動いていて履歴が一部しかない（`git rev-parse --is-shallow-repository` が true）ときは、先に `git fetch --unshallow`
4. 今日作ったり変えたりしたファイル（3で分かったもの。中身は必要なところだけ読む）

## 手順
1. 上の材料を集める。メモも変更の記録も何も無ければ「今日はまだ記録がありません」と伝えて終わる
2. `daily/今日の日付.md` の **一番最後** に、次の形で日報を書く。ファイルの形は「`# 日付` → `## メモ` → `## 日報`」で固定。すでに「## 日報」がある場合は、「## 日報」から下だけを書き直す（「## メモ」は消さない。日報より下にメモが紛れていたら、先に「## メモ」の末尾へ移す）

    ## 日報（HH:MM 作成）
    ### やったこと
    - （3〜7個。作ったもの・進めたこと）
    ### 決めたこと
    - （0〜5個。無ければ「なし」）
    ### 明日やること
    - （1〜3個。やりかけのこと・次の一手）
    ### ひとこと
    - （1行。今日の進み具合を前向きに一言）

3. できたら、日報の中身を短く見せる
4. 自動実行（ルーティン）から呼ばれたときや「上げて」と言われたときは、日本語のメッセージでコミットして GitHub に上げる。クラウドで動いていて `main` に送れないときは、`claude/` で始まるブランチに送れれば成功扱いにする（パソコンで「GitHubの最新を取り込んで」と言われたときに取り込む）

## こだわり
- 事実だけを書く。やっていないことを書かない
- 1項目は1行。長くしない
- 「明日やること」は、次にすぐ手をつけられる具体的な一手にする

## やらないこと
- メモの部分を消したり書き換えたりしない
- 秘密の情報・個人情報を日報に書かない
```

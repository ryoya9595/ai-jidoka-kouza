## 1. MCP／コネクタとは

**MCP**＝AIに「外の道具」を持たせるための仕組み。
たとえると、AIエージェントという部下に、会社の **カレンダーやメールのアカウントを渡す** イメージです。道具を渡すと、部下はそれを使って仕事ができるようになります。

Claude では、この外の道具を **「コネクタ」** と呼んでいて、画面からボタンを押すだけで追加できます。

つなぐとできること（例）：

- 「今週の予定を見て、作業時間を確保して」→ カレンダーを読んで、予定を入れる
- 「今日届いた大事なメールをまとめて」→ Gmail を読んで要約する
- 「この議事録を Notion に保存して」→ Notion に書き込む

⚠️ 道具を渡す＝**できることが増える**。メールを送る・予定を登録する、といった操作もできるようになります。何ができるようになるかを分かった上でつなぎましょう（→ 5章の注意）。

## 2. つなぎ方（2つの入り口。どちらでも同じ）

### 入り口 A：Claude Code の画面から（おすすめ）

1. Claude Code（Code タブ）を開く。環境は **Local**（ローカル）
2. 入力欄の左の **「＋」ボタン** を押す
3. **「Connectors（コネクタ）」** を選ぶ
4. 一覧から、つなぎたいサービス（例：Google カレンダー）を選んで **「接続（Connect）」**
5. ブラウザが開く → **そのサービスのアカウントでログイン**（本人が入力）→ **「許可」** を押す
6. Claude Code の画面に戻る。コネクタ一覧に「接続済み」になっていれば OK

> ※ 「＋」の中に Connectors が無いときは、環境が **Cloud** か **WSL** になっています。**Local** に切り替えてください（クラウドやルーティンでは、作るときにコネクタを指定します）。

### 入り口 B：claude.ai の設定から

1. ブラウザで **https://claude.ai/customize/connectors** を開く（左メニューの **「カスタマイズ」→「コネクタ」**）
2. つなぎたいサービスの **「接続」** を押す
3. ログイン → 許可（本人が入力）
4. Claude Code（デスクトップアプリ）を開き直すと、同じコネクタが使えるようになります

> 💡 Claude のアカウントでログインしている Claude Code は、**claude.ai でつないだコネクタをそのまま使えます**。Google カレンダー・Gmail などは、Claude Code の画面から押しても **結局 claude.ai 側でログインする流れ** になることがあります。どちらから始めても、最終的に同じ場所につながるので安心してください。

### つながったかの確認

Claude Code にこう送ってみてください。

```
今つながっているコネクタを教えて
```

つないだサービスの名前が返ってくれば OK。

## 3. 接続例：Google カレンダー

### つなぐ

1. 「＋」→「Connectors」→ **Google Calendar** → 「接続」
2. ブラウザで **Google アカウントを選ぶ**（複数ある人は、使いたいカレンダーのアカウントを）
3. 「Claude が次のことを求めています」の画面で内容を読んで **「許可」**（または「続行」）
4. Claude Code に戻る

### テスト①：読むだけ

```
今週の予定を見て、空いている時間に作業時間を入れる案を出して
```

→ カレンダーを読んで、空き時間の案が返ってきます。この時点では、カレンダーには何も書き込まれません。

### テスト②：書き込む

```
その案で、水曜の10時から1時間の作業時間を登録して
```

→ **「登録していいですか？」という確認** が出ます。内容（日時・タイトル）を読んで **許可** → Google カレンダーを開いて、予定が入っているか確認してみてください。

> 💡 モードが **Manual** のときは、外に影響がある操作の前に確認が出ます。**Auto** のときは確認なしで進むことがあるので、慣れるまでは Manual で試すのがおすすめです。
> 💡 AI秘書（04回目）と組み合わせると、「私が朝型なのを踏まえて、今週の作業時間を決めて」のようなお願いもできます。

## 4. よく使うコネクタ一覧

| サービス | できること（例） | 条件・メモ |
|---|---|---|
| **Google カレンダー** | 予定を読む・段取りを考える・予定を登録する | Google アカウント |
| **Gmail** | メールを読んでまとめる・返信の下書きを作る | Google アカウント。送信は確認が出る |
| **Notion** | ページを読む・書き込む | Notion アカウント。許可するページを選べる |
| **freee** | 会計データを確認する | freee のアカウント |
| **Zoom** | 会議の記録（要約・文字起こし）を確認する | **Zoom 側が有料プラン（Workplace Pro 以上）＋ AI Companion の設定が必要** |
| Google ドライブ／スプレッドシート | ファイルを探す・読む・書く | Google アカウント |
| X（旧 Twitter） | — | **公式コネクタは無い**（撮影時点）。この講座では扱いません |

> つなぎたいサービスがあるときは、Claude Code に「**〇〇とつなげる？何が必要？**」と聞いてみてください。一覧に無いサービスでも、サービス側が MCP を用意していれば「カスタムコネクタ」として追加できることがあります（上級）。

## 5. 注意（3つ＋1つ）

1. **外に影響がある操作は、必ず確認してから許可する**
   メールの送信・予定の登録・ページの書き込みなど。Claude Code が「〇〇していいですか？」と聞いてきたら、**何をしようとしているかを読んでから** 許可する。読まずに許可しない。
2. **使わないコネクタはオフにする**
   つないでいるコネクタが多いと、Claude Code が毎回読み込む情報が増えて、使用量も増えます。**使うときだけオン**がおすすめ。
   - オフ・接続解除：Claude Code の **設定 → コネクタ**、または「＋」→「Connectors」→ **「Manage connectors（コネクタを管理）」**。claude.ai なら **カスタマイズ → コネクタ** から「接続解除」
3. **サービスによって、できること・条件が違う**
   例：Zoom は Zoom 側の有料プラン＋設定が必要。freee は freee のアカウントが必要。
4. **会社・チームのアカウントは、管理者に確認してから**
   会社の Google や Notion をつなぐと、Claude が会社のデータを読めるようになります。勝手につながず、管理者に「つないで OK か」を確認してください。会社のプラン（Team／Enterprise）では、管理者がコネクタを有効にしないと一覧に出ないこともあります。

## 6. うまくいかないとき

| 症状 | 原因 | 対処 |
|---|---|---|
| 「＋」の中に「Connectors」が無い | 環境が Cloud／WSL になっている | 入力欄の下の環境を **Local** にする。または入り口 B（claude.ai）からつなぐ |
| 「接続」を押してもブラウザが開かない | ポップアップが止められた／アプリが古い | もう一度押す。ダメなら入り口 B（claude.ai）からつなぐ。アプリを最新にする |
| Google のログイン画面で「このアプリは確認されていません」 | 通常は出ない。別アカウント混在の可能性 | いったん閉じて、使いたい Google アカウントだけでログインしたブラウザでやり直す |
| つないだのに Claude Code が「カレンダーにアクセスできない」と言う | アプリが接続前の状態を覚えている | **Claude のアプリを完全に終了して開き直す**。それから「今つながっているコネクタを教えて」で確認 |
| 別の Google アカウントのカレンダーが読まれる | ログイン時に違うアカウントを選んだ | コネクタを接続解除 → 使いたいアカウントで再接続 |
| 予定の登録で確認が出ずに登録された | モードが Auto | 慣れるまでは **Manual** にする（送信ボタンの横のモード） |
| Zoom がつながらない／記録が出ない | Zoom 側の条件を満たしていない | Zoom が Workplace Pro 以上か、AI Companion が有効かを Zoom の設定で確認 |
| 「組織の管理者が許可していません」のような表示 | 会社アカウントの制限 | 管理者に相談。個人の Claude アカウントなら出ない |

それでも解決しないとき → 出ているメッセージやスクショを Claude Code に貼って「直して」と送ってください。

## 今回の「やってみよう」

普段使っているサービスを **1つ**、Claude Code につないでみてください。
つないだ画面のスクショをアウトプット部屋に投稿！（カレンダーの予定など、個人的な内容が映る部分は隠して OK）

## 付録：Claude Code がこのページで案内するときのメモ

- 最初に聞くこと（1回のメッセージで）：① つなぎたいサービス　② 今どの手順まで進んだか　③ 止まっている画面に何と書いてあるか
- ログイン・許可は **本人がブラウザで**。パスワードや認証コードは聞かない・入力しない
- 接続後は「今つながっているコネクタを教えて」に答える形で、自分が使えるコネクタを確認して伝える
- 書き込み系（予定登録・メール送信・ページ更新）は、実行前に **何を・どこに・いつ** を1行で見せて OK をもらってから実行する
- 会社のアカウントの話が出たら「管理者に確認してから」と案内する
- 画面の名前が違うときは公式（ https://code.claude.com/docs/en/desktop#connect-external-tools ／ https://code.claude.com/docs/en/mcp ）を読んで、最新の名前で案内する

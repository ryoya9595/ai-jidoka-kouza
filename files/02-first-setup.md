# 手順ページ：Claude Code のダウンロードと初期設定（Mac／Windows）

> 🤖 **Claude Code へ**：このURLを渡されたら、受講生の状況（Mac か Windows か・どこまで進んだか・何の画面で止まっているか）を聞いて、この手順のどこで困っているかに合わせて案内する。1〜3手順ずつ、やさしい日本語で。アカウント作成・支払い・パスワード入力は受講生本人がやる（代わりにやらない）。

> RISE「AI自動化講座」02回目の配布物。**人が読む手順書** です。動画と同じ順番で書いてあります。
> 困ったら、このページのURL（ https://ryoya9595.github.io/ai-jidoka-kouza/files/02-first-setup.md ）を Claude Code（または claude.ai のチャット）に貼って「ここで止まっています」と伝えると、続きを案内してくれます。
> 画面の見た目は、アップデートでよく変わります。名前が少し違っても慌てず、似たボタンを探してください。どうしても見つからないときは公式ドキュメント（ https://code.claude.com/docs/en/desktop-quickstart ）を確認。

## 0. ゴール

Claude Code の「Code」の画面で、AIと会話ができている状態にする。

やることは3つ。**一度やれば、もうやる必要はありません。**

| 順番 | やること | かかる時間 |
|---|---|---|
| 1 | Claude のアカウントを作って、有料プラン（Pro 以上）に入る | 5〜10分 |
| 2 | Claude のデスクトップアプリを入れて、「Code」を開く（「Gitが必要です」と出たら手順4） | 10〜15分 |
| 3 | GitHub のアカウントを作る（無料・今は作るだけ） | 5分 |
| 4 | Chrome を使っている人：拡張機能「Claude in Chrome」を入れる（手順7） | 3分 |

## 1. Claude のアカウントと有料プラン

Claude Code は **無料プランでは使えません**。Pro 以上の有料プランが必要です。

| プラン | 料金（撮影時点） | この講座で |
|---|---|---|
| Free | 0円 | ✕ Code が開けない |
| **Pro** | 月20ドル（年払いだと月17ドル相当） | ◎ 基本これでOK |
| Max | 月100ドル〜 | 使用量の上限にすぐ達する人向け |

※ 料金は変わることがあります。最新は公式の料金ページで確認 → https://claude.com/pricing

### 手順

1. ブラウザで https://claude.ai を開く
2. **アカウントを作成**（Google アカウントでも登録できます。メールアドレスでも OK）
3. ログインしたら、画面 **左下の自分の名前（アカウント）** を押す → **「プランをアップグレード」**
4. **Pro** を選んで、支払い情報を入れる（**本人が入力**。この画面は動画では映していません）
5. 完了したら、左下のアカウント表示が「Pro」になっているか確認

> 💡 すでに Pro 以上に入っている人は、この手順は飛ばして OK。
> 💡 月払いか年払いかは、どちらでも講座には影響しません。

## 2. デスクトップアプリのダウンロードとインストール

Claude Code は、Claude の **デスクトップアプリの中に入っています**。アプリを入れれば、他のソフト（Node.js など）は要りません。

ダウンロードページ → **https://claude.com/download**

### 🍎 Mac の場合

1. ダウンロードページで **macOS** を選んで **ダウンロード**（`.dmg` というファイルが落ちてきます）
2. 落ちてきたファイルを **ダブルクリックで開く**
3. 開いた窓の中の **Claude のアイコンを「Applications（アプリケーション）」フォルダへドラッグ**
4. **Launchpad** または **アプリケーションフォルダ** から Claude を起動
5. 「インターネットからダウンロードされたアプリです。開いてもよろしいですか？」と出たら **「開く」**

> 対応：macOS 11（Big Sur）以降

### 🪟 Windows の場合

1. ダウンロードページで **Windows** を選んで **ダウンロード**（インストーラーが落ちてきます）
2. 落ちてきたファイルを **ダブルクリック**
3. 「このアプリがデバイスに変更を加えることを許可しますか？」と出たら **「はい」**
4. あとはインストーラーの案内どおり。終わったら **スタートメニュー** から Claude を起動

> 対応：Windows 10 以降
> ※ 最近の Surface など ARM のパソコンの人は、ダウンロードページの「ARM64」版を選びます。分からなければ普通の（x64）版でまず試して、入らなければ ARM64 を試してください。

## 3. 起動 → ログイン → 「Code」に切り替える

1. Claude のアプリを起動する
2. **ログイン** を押す → ブラウザが開くので、**手順1で作ったアカウント** でログイン（Google で登録した人は Google でログイン）
3. ブラウザに「アプリに戻ってください」と出たら、Claude のアプリに戻る
4. 画面 **上の真ん中** に、**「チャット」「Cowork」「Code」** の切り替えがあります。**「Code」** を押す
5. 「Code」を押したときに **アップグレードをすすめる画面** が出たら、まだ有料プランになっていません → 手順1へ戻る
6. 「オンラインでサインインしてください」と出たら、ブラウザでサインインを済ませて、**アプリを一度終了して開き直す**

「Code」の画面が開けば OK。

---

## 4. 「ローカルセッションにはGitが必要です」と出たら

**なぜ要るか**：Claude Code は、ファイルの履歴やセッションの切り分けに「Git」という道具を裏で使います。皆さんが直接触ることはありません。出なかった人は、この手順は飛ばしてOKです。

### 🪟 Windows の方
1. 赤い文字の下にある **「Git for Windows をダウンロード」** を押す（出ていなければ **https://git-scm.com/download/win** を開く）
2. 一番上の **「Click here to download」** を押す（バージョンの数字は変わっていて OK）
3. 落ちてきたファイルを **ダブルクリック**
4. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**
5. インストーラーの画面がたくさん出ますが、**すべて何も変えずに「Next」** → 最後に **「Install」** → **「Finish」**
6. **Claude のアプリを完全に終了して、開き直す**。画面右下の通知領域（タスクトレイ）の Claude のアイコンを右クリック → 終了。閉じただけだと残っていて、警告が消えません

### 🍎 Mac の方
1. 「コマンドライン・デベロッパ・ツールが必要です」というポップアップが出たら **「インストール」** を押す（「入手」は押さない）。5〜20分かかります
2. ポップアップが出ない場合は、「ターミナル」（⌘＋スペースで「ターミナル」と入力）を開いて、次の1行を貼って Enter → 同じポップアップが出るので「インストール」
   ```
   xcode-select --install
   ```
3. 終わったら **Claude のアプリを ⌘Q で終了して、開き直す**

> 💡 分からなくなったら、Claude Code に「**『ローカルセッションにはGitが必要です』と出ています**」と聞いて OK。
> 💡 入れたのに消えない（Windows）：アプリを完全終了していないことがほとんど。それでもダメならパソコンを再起動。

## 5. 画面の説明（Code タブ）

最初は **初期設定のまま** で大丈夫です。どこに何があるかだけ、ざっくり知っておきましょう。

| 場所 | 名前 | 何をするところ |
|---|---|---|
| 上の真ん中 | **チャット／Cowork／Code** の切り替え | **チャット**＝ブラウザの Claude と同じ普通の会話。**Cowork**＝この講座では使わない。**Code**＝この講座で使うのはここ |
| 左側 | **セッション一覧** | 「+ 新しいセッション」で新しい会話を始める。過去のセッション（会話）もここに並ぶ |
| 入力欄の下 | **環境** | 「**Local**（ローカル）」のままで OK。自分のパソコンで動かすという意味 |
| 入力欄の下 | **フォルダの選択**（Select folder） | Claude Code に作業させるフォルダ。次の動画（03回目）で作ります。今は選ばなくて OK |
| 送信ボタンの横 | **モデル** | 頭脳の種類。初期設定のままで OK |
| 送信ボタンの横 | **モード** | **Manual**（マニュアル）＝変更の前に毎回聞いてくれる／**Accept edits**／**Plan**／**Auto**。最初は初期設定のまま。使い分けはあとの動画で |
| 入力欄の左 | **＋ボタン** | ファイルを添える・スキル・コネクタ（15回目で使う）・プラグイン |

### 試してみる

入力欄に、こう送ってみてください。

```
こんにちは。あなたは何ができますか？
```

返事が返ってきたら、Claude Code が動いています！

## 6. GitHub のアカウントを作る（無料）

GitHub は、ざっくり言うと **「ファイルをネット上に保管しておける場所」** です。
この講座では、次の動画で作る「作業フォルダ」を GitHub に保管して、スマホから使えるようにしたり、作ったツールを URL にして公開したりします。**今はアカウントを作るだけで OK。**

1. ブラウザで **https://github.com/signup** を開く
2. **メールアドレス** → **パスワード**（本人が入力） → **ユーザー名** を入れる
   - ユーザー名は **後で作ったツールの URL に入ります**（例：`https://ユーザー名.github.io/...`）。**本名でなくて OK**。英数字とハイフンで、分かりやすい名前に
3. 「Verify（人間の確認）」のパズルが出たら解く
4. メールに届いた **確認コード** を入れる
5. プランを聞かれたら **Free（無料）** を選ぶ。アンケートはスキップして OK

ユーザー名を、どこかにメモしておいてください（次の動画で使います）。

## 7. 🌐 Chrome を使っている方：拡張機能「Claude in Chrome」を入れる

**なぜ要るか**：後の動画で、Claude Code にブラウザを操作してもらいます（SNSの投稿を調べてまとめる・Webページを読んで作業する、など）。そのための拡張機能です。**Chrome を使っていない人は飛ばして OK**（必要になったときに入れれば大丈夫）。

1. Chrome で **https://chromewebstore.google.com/detail/fcoeoabgfenejglbffodgkkbkcdhcgfn** を開く
2. **「Chrome に追加」** → 確認が出たら **「拡張機能を追加」**
3. Chrome 右上の **パズルのアイコン** → **Claude** を押す（ピンのアイコンを押しておくと、次から右上に出ます）
4. **Claude のアカウントでログイン**（Claude Code と同じアカウント）
5. 右側に Claude の画面が開けば OK。使い方は後の動画で

> 💡 拡張機能が使えるプランや対応ブラウザは変わることがあります。最新は講座ページの「必要なプラン（最新）」の欄で確認してください。

## 7. つまずきやすい所と対処

| 症状 | 原因 | 対処 |
|---|---|---|
| 「Code」を押すとアップグレードの画面が出る | 無料プランのまま | 手順1で Pro 以上に入る。入った直後なら、アプリを一度終了して開き直す |
| 「Code」で `Error 403` やログインエラーが出る | ログイン情報が古い | アプリのメニューから **一度サインアウトして、もう一度サインイン**。直らなければアプリを完全に終了（ウィンドウを閉じるだけでなく）して開き直す |
| ログインしたのに別のアカウントになっている | Google と メール、2つのアカウントがある | 左下のアカウント表示でメールアドレスを確認。有料プランに入れた方のアカウントでログインし直す |
| 「Gitが必要です」「Git is required」と出る | Git が入っていない | 手順4（Mac／Windows）を見て入れて、アプリを完全に終了して開き直す |
| 🪟 Git を入れたのに同じエラーが出る | アプリが古い Git の状態を覚えている | Claude のアプリを**完全に終了**してから開き直す。それでもダメならパソコンを再起動 |
| 🍎「開発元を確認できないため開けません」 | Mac のセキュリティ | 「システム設定」→「プライバシーとセキュリティ」→ 下の方の「このまま開く」。または `.dmg` をもう一度 https://claude.com/download から落とし直す |
| 🍎 Claude を起動したら「ファイルへのアクセスを許可しますか？」と出る | フォルダを使う許可 | **「許可」** を押す。あとで作業フォルダを開くときに必要 |
| 画面が真っ白のまま | 読み込み待ち／更新待ち | アプリを再起動。それでもダメなら少し待ってもう一度（起動時に自動で更新が入ることがあります） |
| 動画と画面の見た目が違う | アップデートで変わった | よくあります。似た名前・似た場所のボタンを探す。モードの名前が違うときも「Manual に近いもの」を選べば OK |
| GitHub の確認コードのメールが来ない | 迷惑メールに入っている／アドレスの打ち間違い | 迷惑メールフォルダを確認。来なければ「Resend code」を押す |

それでも解決しないとき → エラーの文章やスクショを、そのまま Claude（チャットでも OK）に貼って「どうすればいい？」と聞いてください。

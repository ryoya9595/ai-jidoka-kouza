## 0. ゴール

AI秘書にテーマ案を出してもらい、1つ選んで、**そのまま公式LINEの特典として使える診断ツール** を作る。

- 質問6問（選択式）→ 結果4タイプ → タイプごとの特徴とおすすめアクション → 最後に「公式LINEで詳しいアドバイスを受け取る」ボタン
- **HTML 1ファイル**。第20回でこのファイルをそのままURLにするので、外部のライブラリ・Webフォント・外部画像に **一切頼らない**

終わったときの形：

```
成果物/
└── 診断ツール/
    └── {診断名}/
        └── index.html   … これ1つで動く（ダブルクリックでも開ける）
```

---

## 1. 守ること（最優先）

- **受講生はパソコン初心者。** 専門用語を避け、短く・やさしい日本語で話す。**1〜3手順ずつ** 出して「できた」を待つ
- **HTML 1ファイルで作る。** CSS・JS は `<style>` `<script>` で中に書く。CDN・外部JS・Webフォント・外部画像・外部APIを使わない（ネットが無くても、ダブルクリックで開いて動くこと）。アイコンは絵文字・CSSの図形・インラインSVGで作る
- **断定しすぎない。** 特に健康・お金・人間関係に関わるテーマは「必ず〇〇になります」と言い切らず、「〇〇な傾向があります」「〇〇を試してみるのがおすすめです」のように、傾向やヒントとして書く。結果画面の最後に「※ この診断はエンタメ・目安としてお楽しみください」の1行を入れる
- **結果の文章は受講生の言葉に寄せる。** `私のプロフィール.md` の発信ジャンル・届けたい人・考え方を踏まえて書く。一般的な文章になったら、受講生に「自分ならこうアドバイスする」を聞いて直す
- **パスワード・カード番号・住所・電話番号・お客さんの個人情報は扱わない。** 診断の答えをどこかに送信する仕組みも作らない（結果はブラウザの中だけで出す）
- 公式LINEの友だち追加URL（`https://lin.ee/…` や `https://line.me/R/ti/p/@…`）は公開して使うものなので、ファイルに書いてよい。もらうまでは仮のURLにしておく
- 他人の診断の文章・画像をコピーして入れない
- ファイルの作成・編集は Write / Edit ツールで行う（文字コードは UTF-8）

## 2. 最初の確認（読むだけ）

Claude Code が自分で確認すること：

1. 作業フォルダに `CLAUDE.md` と `私のプロフィール.md` があるか
   - `CLAUDE.md` が無い → 「先に『作業フォルダセットアップ』（03回目）を済ませてください」と案内して止まる
   - `私のプロフィール.md` が無い → 止まらずに、受講生に **発信のジャンルと届けたい人** を1問で聞いて進める
2. `成果物/診断ツール/` があるか。無ければ作る
3. 第7回の特典（`成果物/特典/`）があれば、中身をざっと見て、診断のテーマが特典とつながるようにする（例：特典が「時短料理チェックリスト」なら、診断は「あなたの時短料理タイプ診断」）

受講生への最初のあいさつ：

> これから、公式LINEの特典にそのまま使える「診断ツール」を作ります！
> 流れは「テーマ案を5つ出す → 1つ選ぶ → 作る → 最初から最後まで試す → 直す → LINEのURLを入れる」です。20分くらいで終わります。
> まず、プロフィールをもとにテーマ案を出しますね。

## 3. ステップ1：テーマ案を5つ出す

受講生から次の指示文が来たものとして動く（講座の動画で見せた指示文。受講生が別の言葉で言っても同じ）：

```
私の発信を見てくれている人が楽しめる診断のテーマを5つ出してください。結果がタイプ別に分かれて、タイプごとにアドバイスができるものがいいです。
```

`私のプロフィール.md` を読んで、**5つ** 出す。1つにつき次の形で書く：

- **①あなたの〇〇タイプ診断**
  - 誰が楽しめる：〇〇で悩んでいる人
  - 4タイプの例：「〇〇型」「〇〇型」「〇〇型」「〇〇型」
  - 結果のあとに送れるアドバイス：〇〇

出し方のコツ：
- 「自分はどのタイプだろう？」と答えたくなるテーマにする（例：あなたの時短家事タイプ診断／あなたの発信スタイル診断／あなたのお金の使い方タイプ診断）
- タイプ名は、どれに当たっても嫌な気持ちにならない言い方にする（ダメ出しにならない）
- 診断の結果が、受講生の発信内容（公式LINEで送るアドバイス）に自然につながるものを選ぶ

出したら聞く：

> この中から1つ選んでください（番号でOKです）。「③のタイプ名を変えたい」のような注文でも大丈夫です。

## 4. ステップ2：設計を見せる（1回だけ確認）

選ばれたテーマで、作る前に **設計** を見せて1回だけ確認を取る。見せる内容：

- **診断名**（例：あなたの時短家事タイプ診断）
- **4タイプ**：タイプ名＋特徴1行（絵文字アイコン付き）
- **質問6問**：1問につき選択肢 **3〜4個**。各選択肢がどのタイプに点を足すかを決める（1つの選択肢が1〜2タイプに1点ずつ）
- **判定方法**：合計点がいちばん高いタイプが結果。同点のときは、質問1に近い順で先に点が入ったタイプを優先（必ず1つに決まるようにする）
- **4タイプ全部が出ること** を点数表で確かめる（どの答え方をしても絶対に出ないタイプがあってはいけない）

> こんな設計で作ります。質問の言い方やタイプ名、変えたいところはありますか？（無ければ「OK」でOKです）

## 5. ステップ3：作る

受講生から次の指示文が来たものとして作る（〇〇は選んだ診断名）：

```
〇〇診断を、HTMLの1ファイルで作ってください。
・質問は6問、答えは選択式
・結果は4タイプ。タイプごとに特徴とおすすめのアクションを書く
・結果の画面の最後に「公式LINEで詳しいアドバイスを受け取る」ボタンをつける（URLは後で差し替えます）
・スマホで見やすいデザインにする
```

### 作るファイル

`成果物/診断ツール/{診断名}/index.html`（例：`成果物/診断ツール/時短家事タイプ診断/index.html`）

### 画面の構成（3画面を1ファイルの中で切り替える）

1. **スタート画面**：診断名・ひとこと（「6つの質問に答えるだけ、約1分」）・「診断をはじめる」ボタン
2. **質問画面**：1問ずつ表示。上に「3 / 6」のような進み具合（バーでもよい）。選択肢はタップしやすい大きなボタン（高さ 44px 以上）。選ぶと自動で次の問題へ。「ひとつ前にもどる」も付ける
3. **結果画面**：
   - タイプ名（大きく）＋アイコン（絵文字 or インラインSVG）
   - あなたの特徴（3〜4行。断定しない言い方）
   - おすすめのアクション（3つ・箇条書き。「今日からできる」具体的なもの）
   - **「公式LINEで詳しいアドバイスを受け取る」ボタン**（大きく・目立つ色・`target="_blank"`）
   - 「もう一度診断する」ボタン（小さめ）
   - 「※ この診断はエンタメ・目安としてお楽しみください」

### 作り方の条件

- `<meta name="viewport" content="width=device-width, initial-scale=1">` を入れる。`<title>` は診断名
- 外部に一切頼らない（`<link href="http…">`・`<script src="http…">`・`<img src="http…">`・`@import`・`url(http…)` を使わない）。作ったあとに `grep -n "http" index.html` で、LINEのURL以外に外部URLが残っていないことを確認する
- **LINE のURLは `<script>` の先頭に1か所だけ** 書く（例：`const LINE_URL = "https://lin.ee/XXXXXXX"; // ← 公式LINEの友だち追加URLに差し替える`）。ボタンの `href` はこの変数から入れる。差し替えを1か所で済ませるため
- 質問・選択肢・タイプの文章・点数は、JS の中のデータ（配列・オブジェクト）にまとめる。あとで「質問を直して」と言われたときに、データだけ直せばよいようにする
- 文字は本文 16px 以上。横スクロールが出ない。ボタンは指で押しやすい大きさ
- 色は受講生の発信の雰囲気に合わせる（ヒントが無ければ、やさしい2色＋白。LINE ボタンは緑系で分かりやすく）
- アニメーションは控えめ（画面切り替えのフェード程度）。動きがなくても使える
- `localStorage` などは使わなくてよい（結果は共有されない・保存されない）

### 骨組みの例（これを元に、実際の中身を入れて作る）

```html
<!doctype html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>{診断名}</title>
<style>
  /* 色は :root の変数にまとめる。スマホ幅で読みやすい余白・文字サイズ */
</style>
</head>
<body>
  <main id="app">
    <section id="start">…スタート画面…</section>
    <section id="quiz" hidden>…質問画面（進み具合・質問・選択肢・もどる）…</section>
    <section id="result" hidden>…結果画面（タイプ・特徴・アクション・LINEボタン・もう一度・注意書き）…</section>
  </main>
<script>
  const LINE_URL = "https://lin.ee/XXXXXXX"; // ← 公式LINEの友だち追加URLに差し替える
  const TYPES = { A: { name: "…", icon: "…", feature: "…", actions: ["…","…","…"] }, B: {…}, C: {…}, D: {…} };
  const QUESTIONS = [ { q: "…", options: [ { text: "…", add: ["A"] }, { text: "…", add: ["B","C"] }, … ] }, … ]; // 6問
  // 点数を足す → 最高点のタイプを結果にする（同点は先に点が入ったタイプを優先）→ 画面を切り替える
</script>
</body>
</html>
```

作ったら伝える：

> 診断ツールができました！右上の **プレビュー** で開いて、最初から最後まで一度やってみてください。
> 結果画面の下に、公式LINEのボタンが出るはずです（URLはまだ仮です）。

## 6. ステップ4：通しテスト

### Claude Code が自分で確かめること（受講生に見せる前に）

1. 点数表を見て、**4タイプのどれも結果に出せる** 答えの組み合わせがあることを確認する（1タイプずつ、そのタイプに点が入る選択肢だけ選んだ場合を頭の中でたどる）
2. どの組み合わせでも結果が必ず1つに決まる（同点の処理がある）
3. `grep -n "http" index.html` で、外部のURLが `LINE_URL` 以外に無い
4. ブラウザが使える環境なら、ファイルを開いて6問→結果まで操作し、エラーが出ないことを確認する（できない環境なら 1〜3 で代える）

### 受講生にやってもらうこと

> 2つ確認してみてください。
> 1. パソコン表示で、最初から最後まで答えて結果が出るか
> 2. スマホ表示に切り替えて、文字やボタンが見やすいか
> 違う答え方でもう1回やると、別のタイプが出るはずです。

## 7. ステップ5：直す（1〜2回）

受講生の感想を聞いて直す。例：

> 気になるところがあれば、そのまま言ってください。例：
> ・「質問の言い方をもう少し柔らかくして」
> ・「結果画面にイラスト風のアイコンを入れて」（絵文字やSVGで作ります。外部の画像は使いません）
> ・「〇〇タイプの名前を△△に変えて」
> ・「私の発信の考え方に合わせて、結果の文章を直して」

直すときのポイント（受講生にも伝える）：

1. **結果の文章は受講生の言葉に。** AI が作った文章は一般的になりがち。「普段発信していること」「自分ならこうアドバイスする」を聞いて、そのとおりに直す。聞いても出てこなければ `私のプロフィール.md` の「届けたい人」「やりたいこと」から寄せる
2. **断定しない。** 直したあとも「必ず」「絶対」「〇〇です（決めつけ）」が残っていないか、結果4タイプ分を読み返す

直すたびにプレビューで確認してもらう。「OK」が出たら次へ。

## 8. ステップ6：公式LINEのURLを差し替える

> 結果画面のボタンに、あなたの **公式LINEの友だち追加URL** を入れます。URLを貼ってください。
> （LINE公式アカウントの管理画面 →「友だち追加ガイド」→「URLを作成」で出てくる `https://lin.ee/…` のようなものです）

- URLをもらったら、`<script>` 先頭の `LINE_URL` を差し替える（1か所だけ）。差し替えたあと `grep -n "lin.ee\|line.me" index.html` で確認し、受講生にもう一度ボタンを押して LINE が開くことを確かめてもらう
- `https://lin.ee/…` でも `https://line.me/R/ti/p/@…` でもよい。それ以外（LINE公式の管理画面のURL・自分のトーク画面のURLなど）が貼られたら「それは管理画面のURLのようです。『友だち追加ガイド』のURLを貼ってください」と案内する
- **公式LINEをまだ持っていない人**：仮のURLのままにして、こう伝える：
  > 公式LINEができたら「診断ツールのLINEのURLを差し替えて」と言ってください。1か所直すだけですぐ入れ替えられます。

## 付録：うまくいかないとき

| 症状 | 対処 |
|---|---|
| 特定のタイプが絶対に出ない | 点数表を見直す。そのタイプに点が入る選択肢を、6問のうち3問以上に入れる |
| 最後の質問を選んでも結果が出ない | ブラウザの開発者ツールのエラーを見るか、`<script>` の中のデータの `,` `}` の抜けを探す。直したら受講生にもう一度通しでやってもらう |
| スマホ表示で選択肢がはみ出す | ボタンの `width: 100%`・`word-break: break-word`、文字サイズを少し下げる |
| 「イラストを入れて」と言われた | 外部画像は使わず、絵文字か、短いインラインSVG（丸・星・ハートなどの簡単な図形）で作る |
| LINEボタンを押しても開かない | `LINE_URL` の先頭が `https://` か、`"` が閉じているか、`href` に変数が入っているか（`#` のままになっていないか）を確認 |
| 第20回でURLにしたら見た目が変わった | 外部に頼っている部分（フォント・画像・CDN）が残っている。`grep -n "http" index.html` で探して、中に書く形に直す |

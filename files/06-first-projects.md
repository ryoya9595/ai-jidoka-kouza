# お題の例（そのまま貼れる指示文3つ）：まずゲームとHPを作ってみよう

> この配布物は **受講生が読むためのもの** です。下の指示文をコピーして、Claude Code にそのまま貼るだけで使えます。
> RISE「AI自動化講座」06回目の配布物。動画で実演した「紹介ページ」「ブロック崩し」と同じ指示文に、自由枠を1つ足しています。
> ※ Claude Code にこのURLを貼った場合：Claude Code は `curl` で全文を読み、受講生に「どのお題から作りますか？」と聞いてから進める。この配布物を作業フォルダには保存しない。

---

## はじめに：この回の考え方（30秒）

- 自分でプログラムを書くのではなく、**日本語でお願いして AI に作ってもらう**（バイブコーディング）
- コツは **最初から完璧を目指さないこと**。ざっくり頼んで一度形にしてもらい、見ながら「ここをこうして」と直していく
- この流れは、後の回で作る特典や診断ツールでも同じ。ここで体に入れておく

### 進め方はいつも同じ3ステップ

1. 下の指示文をコピーして Claude Code に貼る → 送信
2. 右上の **プレビュー** で見る（パソコン表示／スマホ表示を切り替えてみる）
3. 気になるところを日本語で直してもらう（直し方の例文は下にあります）

作ったものは、作業フォルダの `成果物/` の中にファイルとして保存されます（例：`成果物/紹介ページ/`）。後の回で、これをURLにして人に見てもらえるようにします。

## お題①：ホームページ系「自分の紹介ページ」

AI秘書（04回目で作ったもの）はあなたのプロフィールを知っているので、それをもとに作ってもらいます。

```
私のプロフィールをもとに、自分の紹介ページを作ってください。スマホでも見やすいようにしてください。
```

- まだ AI秘書を作っていない人は、代わりにこう貼ってください（{} の中を自分のことに書き換える）：

```
自分の紹介ページを作ってください。スマホでも見やすいようにしてください。
・名前（ニックネームでOK）：{〇〇}
・やっていること：{例：30代向けの時短料理をInstagramで発信}
・届けたい人：{例：仕事と家事で毎日いっぱいいっぱいな人}
・ひとこと：{例：15分で作れる晩ごはんを毎日投稿しています}
```

- 本名・住所・電話番号など、個人を特定できる情報はページに入れない（ニックネームで十分）

## お題②：ゲーム系「ブロック崩し」

```
スマホでもパソコンでも遊べる、簡単なブロック崩しゲームを作ってください。
```

- できたらプレビューで遊んでみる。パソコンはマウス、スマホ表示は指でなぞる動きで確認
- 別のゲームにしたい人は「ブロック崩し」の部分を差し替えるだけでOK：
  - `もぐらたたきゲーム`
  - `神経衰弱（カードめくり）ゲーム`
  - `落ちてくるものをキャッチするゲーム`
  - `3択クイズゲーム（問題は{自分の発信ジャンル}に関するもの10問）`

---

## お題③：自由枠「ボタンを押すと今日の一言が出るページ」

自分の発信ジャンルに寄せやすい、いちばん簡単なお題です。

```
ボタンを押すと、{30代の働くママ}向けの「今日の一言」がランダムで1つ出るページを作ってください。
・一言は20個用意する（{毎日がんばっている人を軽くする、やさしい応援メッセージ}）
・押すたびに違う一言が出る
・スマホで見やすい、やさしい色合いにする
```

- `{}` の中を自分の発信に合わせて書き換える。例：
  - `{筋トレ初心者}` 向けの `{今日やる1種目}`
  - `{副業を始めたい会社員}` 向けの `{今日の小さな一歩}`
  - `{占い好きな人}` 向けの `{今日のラッキーアクション}`
- 自分が「遊んでみたい」「使ってみたい」と思えるものなら、お題は何でも大丈夫です

## 直し方の例文（出てきたものを見ながら貼る）

### 見た目を直す

```
もう少し明るい色にしてください
```
```
文字をもう少し大きくしてください
```
```
全体をやさしい雰囲気（丸み・パステル）にしてください
```

### 一部分だけ直す（プレビューの「要素選択」を使う）

プレビューの要素選択で、ボタンや見出しなど **1か所だけ選んでから** 貼ると、そこだけ直してくれます。

```
この部分だけ、もっと目立つ色にしてください
```
```
この文章を「{書き換えたい文}」に変えてください
```

### ゲームを直す

```
もう少し難しくしてください
```
```
ボールの色を変えてください
```
```
スコアを表示してください
```
```
ゲームオーバーのときに「もう一度」ボタンを出してください
```

### 困ったときの一言

```
エラーが出て動きません。直してください
```
```
今の直しは元に戻してください
```
```
成果物/{テーマ名}/ のフォルダに保存してください
```

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「許可しますか？」のような画面が出る | ファイルを作る許可を聞かれているので「許可」を押す |
| プレビューに何も出ない | Claude Code に「作ったページをプレビューで開いてください」と頼む。それでも出なければ、作業フォルダの中の `index.html` をダブルクリックしてブラウザで開く |
| スマホ表示で崩れる | 「スマホ表示で見ると崩れているので直してください」とそのまま伝える |
| 何回直しても良くならない | 「一度シンプルな形に戻して、そこから作り直してください」と頼む（最初から完璧を目指さない） |
